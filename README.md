# Building collaborative digital behavioural science: A cross-sector agenda from video games research


## Overview

A two-round Delphi and World Cafe study on priorities in video games research.   

## Reproduciblity instructions

Code to make analyses and plots reproducible. Individual level data not shared due to qualitative nature of the data and the specifics of the consent form we employed.

Run the .Rmd files in the /code directory in numerical order. 

Note that .Rmd files will not run without the .csv data files, which are not distributed publicly.
